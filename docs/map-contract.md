# Контракт карти (чернетка, узгодити з автором моделей)

Друг робить моделі в Blender і розставляє їх у Roblox Studio. Код їх **не створює**, а **знаходить**.
Щоб це працювало, домовляємося про кілька простих правил. Якщо модель їх виконує, код підхопить її сам,
навіть якщо змінити форму, розмір чи кількість.

## Головна ідея: теги й атрибути, а не точні шляхи

У Studio в кожного об'єкта є **Tags** і **Attributes** (вікно Properties, внизу). Код шукає об'єкти за тегом,
тому не важливо, в якій папці лежить модель і як її названо.

| Що це             | Тег (Tags)   | Атрибути (Attributes)                          | Примітка                                              |
| ----------------- | ------------ | ---------------------------------------------- | ----------------------------------------------------- |
| Блок руди         | `OreNode`    | `OreId` (string), напр. `"copper"`             | Model з PrimaryPart або одна Part. Повинна бути Anchored. |
| Зона продажу      | `SellZone`   | немає                                          | Невидима Part (`Transparency = 1`, `CanCollide = false`). |
| Магазин           | `Shop`       | `ShopId` (string), напр. `"surface"`           | Model; код додасть підказку «Натисни E».              |
| Точка відродження | `CampSpawn`  | `LayerId` (number), напр. `1`                  | SpawnLocation або Part.                               |

`OreId` і `LayerId` мають збігатися з ідентифікаторами в `src/shared/config`. Список дійсних id дає розробник.

## Структура Workspace (для порядку, не для коду)

```
Workspace
  Surface/          поверхня: фабрика, магазин, продаж
  Layers/
    Layer1/         один шар = одна модель, щоб потім підвантажувати шари частинами (streaming)
      Ores/
      Camp/
```

## Правила для моделей

- Усе статичне **Anchored**. Не кладіть скрипти в моделі: логіка живе в коді.
- Розумна кількість полігонів (мобільні пристрої). Великі шари краще ділити на шматки.
- Анімації й звуки мають належати власнику гри (або групі), інакше в грі вони не програються.
- Лише власні моделі, текстури й звуки. Жодних чужих брендів і нічого з аніме, яке надихнуло ідею.
- Перед великою зміною зберігайте/публікуйте версію плейсу.

## Що робить код, коли модель зникає

Якщо блок руди позначено неправильно (немає `OreId` або невідомий id), сервер пише одне попередження в Output
і пропускає його. Гра не падає.
