# Контракт карти

Для автора моделей. Друг робить моделі в Blender і розставляє їх у Roblox Studio. Код їх **не створює**, а **знаходить**:
за **тегом** (Tags) і **атрибутами** (Attributes) у вікні Properties. Назва моделі й папка не важливі.

Як тільки на карті з'являється хоч один об'єкт із тегом, сіра заглушка для цього тегу в Studio більше не будується.
Джерело істини в коді: [src/shared/config/map-contract.ts](../src/shared/config/map-contract.ts).

## Теги

| Що це                | Тег         | Атрибут                    | Тип об'єкта                                   | Що робить код                                      |
| -------------------- | ----------- | -------------------------- | --------------------------------------------- | -------------------------------------------------- |
| Блок руди            | `OreNode`   | `OreId` (string)           | Part або Model                                | додає ClickDetector, підпис над блоком              |
| Магазин спорядження  | `Shop`      | немає                      | Part або Model                                | ProximityPrompt «Відкрити»                          |
| Зона скупки          | `SellZone`  | немає                      | Part (можна прозору, `CanCollide = false`)     | ProximityPrompt «Продати»                           |
| Склад на поверхні    | `Warehouse` | немає                      | Part або Model                                | ProximityPrompt «Склад»                             |
| Машина фабрики       | `Machine`   | `MachineId` (string)       | Part або Model                                | ProximityPrompt з назвою машини                     |
| Табір шару           | `CampSpawn` | `LayerId` (number)         | Part або SpawnLocation (код вимикає `Enabled`) | дотик відкриває шар і ставить точку відродження     |
| Точка на поверхні (подорож) | `SurfaceSpawn` | немає                | Part (одна)                                    | сюди телепортує швидка подорож «Поверхня»           |
| Майданчик автобура   | `DrillSite` | `LayerId` (number)         | Part або Model                                | ProximityPrompt «Автобур»                           |
| Стійка скрині        | `Chest`     | `ChestId` (string)         | Part або Model                                | ProximityPrompt з назвою скрині                     |

## Дійсні значення атрибутів

| Атрибут     | Значення                                                                                    |
| ----------- | ------------------------------------------------------------------------------------------- |
| `OreId`     | `copper` (шар 1) · `iron` (шар 2) · `gold` (шар 3) · `titanium` (шар 4) · `obsidian`, `etherium` (шар 5) |
| `LayerId`   | `1` Сірі Пласти, `2` Іржаві Порожнини, `3` Базальтова Глибина, `4` Титанові Ребра, `5` Ефірне Дно (назви 4–5 пропозиції) |
| `MachineId` | `furnace` (Горн), `workbench` (Верстат)                                                     |
| `ChestId`   | `pet_chest`, `speed_chest`, `pickaxe_chest`                                                  |

Неправильний або відсутній атрибут не ламає гру: сервер пише одне попередження в Output і пропускає об'єкт.

## Рекомендована структура Workspace (для порядку, не для коду)

```
Workspace
  Surface/            поверхня: магазин, скупка, склад, машини, скрині
  Layers/
    Layer1/           один шар = одна модель (щоб потім вантажити шари частинами, StreamingEnabled)
      Ores/
      Camp/           SpawnLocation з тегом CampSpawn, LayerId = 1
      DrillSite/
    Layer2/ ...
```

## Правила для моделей

- Усе статичне **Anchored**. Жодних скриптів у моделях: уся логіка живе в коді.
- Блок руди 3–5 studs: гравець має легко влучити мишкою й пальцем на телефоні.
- Табори шарів 2 і 3 мають бути **нижче** за попередні: гравець відкриває шари по черзі, перестрибнути не можна,
  а між відкриттями має минути щонайменше 45 с (захист від телепорту).
- **Глибина для лідерборда** міряється від висоти `SurfaceSpawn` (метри = studs нижче неї × 0.5) і обмежується табором
  першого ще не відкритого шару (`CampSpawn` з його `LayerId`). Тому `CampSpawn` має бути для **кожного** шару
  2..LAYER_COUNT, а табори глибших шарів стоять нижче. Немає табору наступного шару: рекорд глибини не пишеться.
  Остання межа: 99 999 м. Глибина рахується лише над нерухомою геометрією (сервер кидає промінь вниз), тож усе, по
  чому ходять, має бути **Anchored**.
- Табір **не** є точкою появи нових гравців: код вимикає `SpawnLocation.Enabled`. Для старту на поверхні постав
  звичайний `SpawnLocation` без тегу.
- Розумна кількість полігонів (мобільні пристрої). Великі шари краще ділити на шматки.
- Анімації й звуки мають належати власнику гри (або групі), інакше в грі вони не програються.
- Лише власні моделі, текстури й звуки. Жодних чужих брендів і нічого з аніме, яке надихнуло ідею.
- Перед великою зміною зберігайте/публікуйте версію плейсу.
