## Що вже є (стан на 2026-11-24)

Усе нижче працює на сервері, перевірено тестами чистої логіки (207 тестів) і зібрано без помилок.
**У Roblox Studio ще не перевірено**: перший Play-тест попереду (див. чек-лист нижче).

| Система       | Коротко                                                                                                           |
| ------------- | ----------------------------------------------------------------------------------------------------------------- |
| Видобуток     | Клік по блоку руди. Кирка має рівень: слабка кирка не бере руду вищого рівня, над блоком видно, яка кирка потрібна. |
| Кирки         | Залізна → Сталева → Обсидіанова → Ручний бур → Плазмовий бур. Рівень відкриває руду, сила зменшує кількість ударів. |
| Сумка         | Обмежена місткість, 6 рівнів. Повна сумка не дає добувати.                                                         |
| Продаж        | У зоні скупки: розбивка по руді, бонус, точна сума **до** продажу і порівняння «а якщо переробити на фабриці».     |
| Склад         | Вивантаження сумки, продаж усього зі складу, оцінка вигоди від переробки.                                          |
| Фабрика       | Купівля машин. Горн: руда → злитки. Верстат: злитки → деталі. Черга до 10, працює, поки гравця немає.               |
| Шари й табори | 3 шари. Табір відкриває шар (по одному, без перестрибувань) і стає точкою відродження. Смерть без втрат.            |
| Швидкість     | Взуття (6 рівнів) + аура швидкості. Сервер ставить WalkSpeed, стеля 40.                                            |
| Автобур       | Відкривається після проходження шару. Добуває лише руду, яку бере кирка, ~10× повільніше за руки, конвеєр на склад. |
| Скрині        | Улюбленці, аури швидкості, аури кирки. Шанси видно до оплати. Долари або Robux (з перевіркою політики Roblox).      |
| Екіпірування  | 1 аура швидкості, 1 аура кирки, 3 улюбленці. Підсумковий ефект і стелі бонусів, кнопка «найкраще», продаж зайвого.  |
| Підказка      | Один рядок «що робити далі» в HUD.                                                                                 |
| Збереження    | ProfileStore із session locking, ремонт пошкоджених даних, міграції.                                                |

## Ігровий цикл

```
добувай руду ──► сумка повна ──► продай (швидкі гроші)
      ▲                    └──► склад ──► горн/верстат (більше грошей, але час)
      │                                        │
      └── кирка / сумка / взуття / машини ◄────┘
                    │
      глибше ──► табір нового шару ──► автобур на пройденому шарі
                    │
      скрині ──► улюбленці (+ціна) / аури (+швидкість, +руда)
```

## Play-тест у Studio: що перевірити

Запуск: термінал 1 `npm run watch`, термінал 2 `rojo serve`, у Studio плагін Rojo → Connect, потім Play.
Поки моделей друга немає, сервер у Studio сам будує сіру тестову зону (папка `Workspace.DevPlaceholders`).
Для збереження між запусками: Game Settings → Security → Enable Studio Access to API Services.

1. **Старт.** Ліворуч угорі HUD: `$0`, шар, `🎒 0/25`, кирка, склад, ціль. Над блоками руди назва, ціна й кількість ударів.
2. **Видобуток.** Клікай по сірому (вугілля) блоку: смужка прогресу, після 2 ударів `+1 Вугілля`, блок стає прозорим і повертається.
3. **Замок.** Кварц (світлий блок) підписаний `🔒 … Потрібна: Сталева кирка`, клік дає повідомлення, руда не додається.
4. **Повна сумка.** Набери 25 шт.: повідомлення «Сумка повна», HUD `(повна!)`, ціль «продай руду».
5. **Продаж.** Зелена прозора зона → `E`: розбивка, сума, блок «А якщо переробити?», кнопка продажу. Гроші ростуть рівно на показану суму.
6. **Магазин.** Жовта стійка: купи сталеву кирку. Кварц стає доступним, удари по залізу 5 → 3.
7. **Фабрика.** Склад → «Вивантажити сумку». Горн → купити ($500) → `+1` мідний злиток → таймер іде, «Готово» → «Забрати на склад».
8. **Офлайн.** Постав 10 злитків у чергу, вийди з Play, зайди знову: повідомлення «Поки тебе не було…».
9. **Шари.** Дійди до табору 2, потім 3: повідомлення «Відкрито новий шар». Табір 3 без табору 2 нічого не відкриває.
10. **Бур.** Після табору 2 автобур 1 → збудувати → буфер росте, склад поповнюється сам.
11. **Скрині.** Дерев'яні скрині біля магазину: таблиця шансів, відкриття за долари, екран результату.
12. **Екіпірування.** Кнопка ліворуч унизу: бонуси, «Екіпірувати найкраще», швидкість у HUD змінюється, біля персонажа з'являються кульки-улюбленці.

Якщо щось не так, скопіюй червоні рядки з вікна Output (сервер і клієнт) і надішли.
