# Безкоштовні провайдери

Каталог OmniRoute 3.8.53 містить 375 провайдерів. Ми беремо **тільки офіційні API з безкоштовним тарифом**.

> Ліміти змінюються часто, і точних чисел я тут не пишу: вони швидко стають неправдою. Актуальні ліміти дивись у
> кабінеті кожного провайдера.

## Беремо (ключ створюєш ти сам, на сайті провайдера)

| Провайдер (id в OmniRoute) | Де взяти ключ | Що важливо |
|---|---|---|
| `gemini` | aistudio.google.com → Get API key | Найбільший контекст і найщедріші ліміти з безкоштовних, підтримує tool calling. Головний кандидат для Claude Code. На безкоштовному тарифі Google може використовувати запити для покращення моделей. |
| `openrouter` | openrouter.ai → Keys | Тільки моделі з `:free` в назві. Денний ліміт запитів. Не поповнюй баланс, тоді платні моделі не спрацюють. |
| `groq` | console.groq.com | Дуже швидкий, але малий ліміт токенів за хвилину: великі запити Claude Code часто не проходять. Добрий для коротких задач. |
| `cerebras` | cloud.cerebras.ai | Швидкий, але з обмеженим контекстом і денним лімітом. |
| `mistral` | console.mistral.ai | Безкоштовний тариф "Experiment". |
| `nvidia` | build.nvidia.com | Безкоштовні кредити на відкриті моделі. |

## Не беремо

- **`noauth` і `web-cookie`** (duckduckgo-web, cloudflare-playground, веб-сесії інших сервісів): обходять чужі
  сайти, порушують їхні правила, і невідомо, хто отримує код.
- **Невідомі «free»-агрегатори** з каталогу: незрозуміло, хто за ними стоїть і що вони роблять із кодом.
- **OAuth чужих підписок** (`kiro`, `qoder`, `agy` тощо): використовувати споживчу підписку через сторонній проксі
  зазвичай заборонено правилами сервісу. Є ризик блокування акаунта.
- **Твоя підписка Claude через OmniRoute:** не підключай. Claude Code з нею працює напряму, як зараз.

## Як не витратити гроші

1. **Не додавай платіжну картку** в жодного провайдера. Без картки платний запит просто не пройде.
2. Не додавай у OmniRoute платні ключі (OpenAI, Anthropic API тощо).
3. У комбо маршрутів додавай тільки моделі зі списку вище.

## Приватність

Усе, що йде через OmniRoute, отримує провайдер: код, контекст файлів і виводи інструментів. Безкоштовні тарифи
можуть навчатися на цих даних. **Ніколи не пиши в чат паролі, ключі й особисті дані.**
