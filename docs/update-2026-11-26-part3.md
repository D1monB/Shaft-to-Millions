# Частина 3: чек-лист нових фіч (рішення 067–070)

Перевіряй у Play (місце друга). Для швидкої перевірки видай собі гроші через 👑 Dev.

| Фіча | Як перевірити |
|---|---|
| Навчання | Dev → «Скинути ВЕСЬ прогрес» собі. Після входу вгорі картка «Добудь 15 руди» і золота стрілка. ✕ прибирає назавжди. Після копання стрілка веде до продажу, крамниці, ділянки. |
| Меню поступово | Новому гравцю в «⋯ Ще» немає Будов, Аур і Рейду, доки не пройшов кроки. |
| Пропуск квеста | 📜 Квести → під сюжетним «Пропустити цей крок». |
| Календар | «Ще → Календар» → забрати день 1. Другий раз сьогодні не дається. |
| Переродження | «Ще → Переродження». Видай $25M через Dev, натисни двічі. Завод, спорядження й шари скидаються, гроші стають x1.5, речі лишаються. |
| Титули | «Ще → Титули» → одягни відкритий. Інші бачать його над головою. |
| Друзі | Зайди з другом на один сервер: плитка «Друзі тут» +10%. Кнопка «Запросити друзів». |
| Сезонні події | У суботу чи неділю ліворуч плитка «Вихідні: руда x2». |
| Істоти | Копай і чекай ~3 хв: біля руди з'явиться дикий звір. Утримуй його підказку з потрібною рудою в сумці. |
| Меню стрічки | Біля конвеєра кнопка T: швидкість, силос, полірування. |
