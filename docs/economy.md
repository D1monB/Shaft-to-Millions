# Економіка й баланс

Усі числа живуть у [src/shared/config](../src/shared/config). Змінити баланс = змінити запис у конфігу; код не чіпати.
Тести перевіряють **властивості** балансу (див. «Що гарантують тести»), тож випадково зламати прогресію не вийде.
Числа стартові: підкрутимо після Play-тестів.

## Фабрика ([machines.ts](../src/shared/config/machines.ts), [products.ts](../src/shared/config/products.ts))

Склад і черга машини мають рівні (покращення купуються біля машини або складу). Ціни **припущені**, тюнінг після Play-тесту.

| Покращення | Рівень 2 | Рівень 3 | Рівень 4 |
| ---------- | -------- | -------- | -------- |
| Склад (місць: 1 000 → 2 000 → 4 000 → 8 000) | $2 000 | $10 000 | $50 000 |
| Горн, швидкість (×1.25 → ×1.6 → ×2) | $1 500 | $6 000 | $25 000 |
| Горн, черга (10 → 15 → 20 → 30) | $1 000 | $4 000 | $15 000 |
| Верстат, швидкість (×1.25 → ×1.6 → ×2) | $8 000 | $30 000 | $120 000 |
| Верстат, черга (10 → 15 → 20 → 30) | $5 000 | $20 000 | $80 000 |

| Машина  | Ціна   | Рецепт                                   | Час  | Сировина → товар |
| ------- | ------ | ---------------------------------------- | ---- | ---------------- |
| Горн    | $500   | 3 мідь → мідний злиток                   | 6 с  | $15 → $24        |
|         |        | 2 залізо + 1 вугілля → залізний злиток   | 8 с  | $20 → $32        |
|         |        | 2 срібло + 1 вугілля → срібний злиток    | 10 с | $42 → $65        |
|         |        | 2 золото + 1 вугілля → золотий злиток    | 12 с | $92 → $140       |
| Верстат | $3 000 | 2 мідні злитки → мідний дріт             | 10 с | $48 → $80        |
|         |        | 2 залізні злитки → шестерня              | 12 с | $64 → $105       |
|         |        | срібний злиток + дріт → контакт          | 15 с | $145 → $230      |
|         |        | золотий злиток + 2 дроти + кварц → плата | 20 с | $325 → $520      |

Кожен крок дає +50–70% вартості, але коштує часу. Вугілля потрібне як паливо: дешеву руду є сенс збирати.

## Автобури ([drills.ts](../src/shared/config/drills.ts))

| Бур      | Відкривається              | Ціна     | Секунд на одиницю міцності | Буфер |
| -------- | -------------------------- | -------- | -------------------------- | ----- |
| Шар 1    | після табору шару 2        | $2 000   | 6 (вугілля 12 с, залізо 30 с) | 40 |
| Шар 2    | після табору шару 3        | $20 000  | 5                          | 60    |
| Шар 3    | коли з'явиться шар 4       | $150 000 | 4                          | 80    |

Бур добуває лише руду свого шару, яку гравець може добути своєю киркою. Він приблизно в 10 разів повільніший за руки.
Офлайн бур рахується максимум 8 годин, а повний буфер його зупиняє. Конвеєр везе руду на склад, поки там є місце.

## Скрині й предмети ([chests.ts](../src/shared/config/chests.ts), [items.ts](../src/shared/config/items.ts))

| Шанс | Скриня улюбленців ($1 500) | Скриня швидкості ($1 000) | Скриня кирки ($2 000)    |
| ---- | -------------------------- | ------------------------- | ------------------------ |
| 45%  | Кротик +5% продажу         | Подих вітру +5%           | Відблиск +10% руди       |
| 30%  | Рудний жук +10%            | Іскра +10%                | Жар +20%                 |
| 15%  | Ліхтарна міль +18%         | Комета +15%               | Поштовх +35%             |
| 8%   | Кришталева ящірка +30%     | Блискавка +22%            | Призма +55%              |
| 2%   | Золотий голем +50%         | Буревій +30%              | Ядро +80%                |

Продаж зайвого предмета: $50 / $120 / $300 / $800 / $2 000 за рідкістю. Очікувана виручка від перепродажу набагато нижча за ціну скрині.

## Як складаються бонуси ([equipment.ts](../src/shared/features/equipment/equipment.ts))

| Бонус              | Звідки                       | Як рахується                      | Стеля                   |
| ------------------ | ---------------------------- | --------------------------------- | ----------------------- |
| Ціна продажу       | до 3 улюбленців              | сума бонусів, множник `1 + сума`  | +150% (×2.5), загалом ×5 |
| Швидкість          | 1 аура швидкості             | `взуття × (1 + аура)`             | +30%, WalkSpeed ≤ 40     |
| Руда з блоку       | 1 аура кирки                 | 1 шт. + шанс ще однієї            | +100%                    |

Бонуси рахує одна спільна функція: сервер застосовує, клієнт показує ті самі числа. Один предмет не можна врахувати двічі.

## Що гарантують тести

- Кожну руду бере якась кирка; основний ряд кирок, сумки й взуття стають кращими й дорожчими; id предметів унікальні, усі матеріали існують.
- Кожен рецепт дорожчий за свою сировину.
- Бур щонайменше в 5 разів повільніший за ручний видобуток.
- Шанси кожної скрині в сумі дають рівно 100%, а розподіл кидка збігається з показаними шансами.
- Найсильніший можливий набір предметів не виходить за жодну стелю гри.
- Перепродаж предметів ніколи не окуповує скриню.
