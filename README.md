# Shaft to Millions (working title)

A Roblox game about descending a deep layered mine shaft and growing a factory on the surface.
Written in TypeScript with roblox-ts, synced to Roblox Studio with Rojo.

## Setup

1. Install Node 24+, [Rokit](https://github.com/rojo-rbx/rokit) and Roblox Studio with the Rojo plugin.
2. `rokit install` (rojo, lune), then `npm ci`.
3. `npm test` to check that everything builds and tests pass.

## Working in Studio

- Terminal 1: `npm run watch`
- Terminal 2: `rojo serve`
- Studio: Rojo plugin, Connect (port 34872).
